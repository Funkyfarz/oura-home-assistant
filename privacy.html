Privacy Policy

Home Assistant Oura Integration

This is a private, non-commercial Home Assistant integration used to access personal data from an Oura Ring through the Oura API.

Data Collection

The application accesses data provided by the user's Oura account through the Oura API. This may include health, sleep, activity, heart rate, readiness, stress, workout and other data made available through the permissions granted to the application.

Use of Data

Oura data is used solely for the user's personal use within their Home Assistant installation. The data is used to provide sensors, statistics and automations within Home Assistant.

Data Storage

Data retrieved from Oura may be stored locally by Home Assistant on the user's own Home Assistant system. The application does not operate a separate external database for Oura data.

Data Sharing

Oura data is not sold, rented or provided to third parties by this application. The application does not use Oura data for advertising or commercial purposes.

Access and Authentication

Access to the Oura API is granted through OAuth authentication. OAuth credentials are stored within the user's Home Assistant installation and are used only to access the user's Oura account.

Data Deletion

The user can remove the Oura integration from Home Assistant and delete locally stored data at any time. Access to the Oura API can also be revoked through the user's Oura account.

Changes to this Policy

This privacy policy may be updated if the functionality or data handling of the application changes.

Contact

For questions regarding this application or its use of data, please contact the application owner using the contact information associated with the Oura developer application.
